# V2.0 RAG Quality Closure Implementation

Updated: 2026-07-26

## Scope implemented

- API package version is `2.0.0` in `services/api/pom.xml`.
- Web package and lockfile metadata are `2.0.0` in `services/web/package.json` and the root lockfile package entries.
- `RagEvalService` writes V2.0 quality closure metrics into `RagEvalRun.metrics`.
- Web types and `RagEvalPanel` render the V2.0 Quality dashboard cards.
- API and Web tests cover the new metrics and card rendering.

## API implementation

`RagEvalService.metrics(...)` now emits the V2.0 closure map set:

- `releaseReadiness` is versioned as `V2.0` and keeps the release score, blockers, required evidence, artifact keys, and action recommendation.
- `realQueryFeedback` builds immutable feedback candidates with `id`, `sourceRunId`, `sourceResultId`, `retrievalProfile`, `reviewStatus=OPEN`, optional `promotedCaseId`, `suggestedAction`, and `judgeStatus`.
- `experimentMatrix` captures TopK, profiles, retrieval modes, case/evaluation counts, and rerank evidence.
- `answerQuality` uses deterministic citation and hard-negative rules and stores risk cases with grounded/citation/hallucination flags.
- `onlineObservability` stores fallback, no-answer, latency, degraded profile count, and `sloStatus`.
- `dataIndexGovernance` stores expected-source coverage, missing-source count, multi-document/ambiguous counts, embedding dimensions, and `governanceStatus`.
- `onlineSlo` evaluates pass rate, fallback rate, P95 latency, and profile regression objectives.
- `canaryGate` combines release gate status, online SLO, answer-quality judge status, candidate profile presence, and actual profile gate statuses.
- `v2QualityClosure` reports `READY` only when the release gate and canary gate both pass.
- `releaseReport` records the final recommended action and evidence keys.

## Web implementation

- `services/web/src/types/index.ts` defines V2.0 metric interfaces for SLO, canary, release report, and closure.
- `services/web/src/components/RagEvalPanel.tsx` renders cards for V2.0 Quality closure, Online SLO, and Canary gate, and continues rendering readiness, feedback, experiment matrix, answer quality, observability, and governance evidence.
- The canary card includes `profileGateStatuses` so blocked candidate gate decisions are visible in the dashboard.

## Tests

- `RagEvalServiceTest#metricsExposeV20QualityClosureRollupsAndReleaseReport` covers blocked release evidence, feedback candidates, risk cases, SLO breach, canary rollback, closure blocked state, and release report fields.
- `RagEvalServiceTest#v20ClosurePromotesPassingCandidateAndAcceptsCorrectNoAnswerCases` covers the promote path and verifies that correct hard-negative/no-answer cases are not hallucination risks.
- `RagEvalServiceTest#v20CanaryRollsBackWhenProfileGateBlocksEvenIfEvalMetricsPass` covers the case where aggregate metrics pass but the actual profile gate blocks canary promotion.
- `RagEvalPanel.test.tsx` covers the V2.0 dashboard cards and canary profile gate status display.
