> **中文说明：** 本手册说明 V1.4.2 治理运维摘要接口的授权、响应结构、冒烟检查及健康状态判定方法。

**状态：** 开发中

V1.4.2 在 V1.4.1 上传和摄取治理能力之上，增加了简洁的只读运维摘要。

## 端点

`GET /api/v1/ops/governance-summary`

授权遵循现有的 `/api/v1/ops` 策略，需要拥有 `OPS_ADMIN` 权限的操作员会话或 API 访问凭证。

## 响应结构

响应包含以下顶级字段：`generatedAt`、`uploadQuota`、`ingestJobs`、`ingestOutbox`、`failureNotifications`、`vectorCleanup` 和 `alerts`。

## 冒烟检查

针对本地或已部署的 API 运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/smoke-governance-summary.ps1 `
  -BaseUrl http://localhost:8080 `
  -ApiKey $env:DUPI_API_KEY `
  -OutFile evidence/governance-summary-smoke.json
```

脚本会验证必需的顶级字段并写入可审阅的证据。它会记录是否配置了 API Key，但不会打印或写入密钥值。

## Pester 检查

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "Import-Module Pester; Invoke-Pester -Path scripts/tests/smoke-governance-summary.Tests.ps1 -CI"
```
