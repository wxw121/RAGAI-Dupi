# V2.0 RAG 质量体系封板实施文档

更新日期：2026-07-26

## 已实现范围

- `services/api/pom.xml` 中 API 版本为 `2.0.0`。
- `services/web/package.json` 和 lockfile 顶层 package 元数据为 `2.0.0`。
- `RagEvalService` 将 V2.0 质量封板指标写入 `RagEvalRun.metrics`。
- Web 类型和 `RagEvalPanel` 展示 V2.0 Quality dashboard 卡片。
- API 与 Web 测试覆盖新增指标和卡片展示。

## API 实现

`RagEvalService.metrics(...)` 现在输出以下 V2.0 closure 指标：

- `releaseReadiness`：版本统一为 `V2.0`，保留发布分数、阻断项、证据要求、artifact key 和建议动作。
- `realQueryFeedback`：生成不可变反馈候选，包含 `id`、`sourceRunId`、`sourceResultId`、`retrievalProfile`、`reviewStatus=OPEN`、可选 `promotedCaseId`、`suggestedAction` 和 `judgeStatus`。
- `experimentMatrix`：汇总 TopK、profiles、retrieval modes、case/evaluation 数和 rerank 证据。
- `answerQuality`：使用确定性引用与 hard-negative 规则，保存带 grounded/citation/hallucination 标记的风险用例。
- `onlineObservability`：保存 fallback、无答案、延迟、退化 profile 数和 `sloStatus`。
- `dataIndexGovernance`：保存期望来源覆盖、缺失来源、多文档/歧义用例、embedding 维度和 `governanceStatus`。
- `onlineSlo`：评估通过率、fallback rate、P95 延迟和 profile regression 目标。
- `canaryGate`：结合 release gate、online SLO、answer-quality judge、候选 profile 存在性和实际 profile gate 状态。
- `v2QualityClosure`：只有 release gate 与 canary gate 都通过时才返回 `READY`。
- `releaseReport`：记录最终建议动作和证据 key。

## Web 实现

- `services/web/src/types/index.ts` 新增 SLO、canary、release report 和 V2 closure 的类型。
- `services/web/src/components/RagEvalPanel.tsx` 新增 V2.0 Quality closure、Online SLO 和 Canary gate 卡片，并继续展示 readiness、feedback、experiment matrix、answer quality、observability 和 governance。
- Canary 卡片展示 `profileGateStatuses`，使候选 profile gate 阻断原因可见。

## 测试

- `RagEvalServiceTest#metricsExposeV20QualityClosureRollupsAndReleaseReport` 覆盖阻断路径：反馈候选、风险用例、SLO breach、canary rollback、closure blocked 和 release report 字段。
- `RagEvalServiceTest#v20ClosurePromotesPassingCandidateAndAcceptsCorrectNoAnswerCases` 覆盖通过路径，并验证正确 hard-negative/no-answer 不计为幻觉风险。
- `RagEvalServiceTest#v20CanaryRollsBackWhenProfileGateBlocksEvenIfEvalMetricsPass` 覆盖聚合指标通过但实际 profile gate 阻断时仍 rollback。
- `RagEvalPanel.test.tsx` 覆盖 V2.0 dashboard 卡片和 canary profile gate 状态展示。
