# AI 新增 RAG 评估用例

## 目标

让 AI 生成评估用例成为“评估用例”模块中的常驻能力，而不再只在存在失效用例时出现。用户可以选择当前知识库的一篇或多篇已完成文档，为每篇生成指定数量的新用例，并在预览确认后追加保存。该流程不得删除、覆盖或隐式修改现有有效用例。

本次同时修复逗号分隔输入框的空格异常：编辑“附加来源文件”或“期望关键词”时，逗号后的连续空格始终规范为一个，不能随着输入继续累积。

## 用户体验

“评估用例”标题右侧常驻显示“AI 新增用例”按钮，与现有的手工“添加评估用例”并列。

点击后展开 AI 新增面板：

- 列出当前知识库中状态为“已完成”的实际文档；
- 支持多选文档；
- 默认每篇生成 2 条，可调整为 1～5 条；
- 未选择文档时不能生成；
- 点击“生成预览”只调用 AI，不写入数据库；
- 生成期间显示明确的等待状态，并阻止重复提交。

预览按文档分组展示每条候选用例的标识、问题、来源文件和期望关键词。用户可以取消，也可以点击“确认新增”。确认新增只追加预览中的用例，成功后刷新用例列表并关闭面板。

现有的失效用例提醒继续保留。它仍使用“替换失效并补足覆盖”的修复流程，按钮文案改为“AI 修复失效用例”，与常驻的“AI 新增用例”明确区分：

- **AI 新增用例**：用户选择文档，追加新用例，不删除任何现有用例；
- **AI 修复失效用例**：删除预览中确认的失效用例，并按当前知识库文档补足覆盖。

两个流程都必须先预览后确认，不能静默写入。

## 输入框行为

“附加来源文件”和“期望关键词”使用独立的原始文本状态，避免输入过程中反复执行数组拆分与拼接。

输入时仅规范逗号后的空白：

- `a,b` 保持可正常继续输入；
- `a, b` 保持为 `a, b`；
- `a,    b` 自动变为 `a, b`；
- 不修改关键词内部合法空格，例如 `HTTP 方法`；
- 点击保存时再按逗号拆分、清理每项首尾空格并移除空项。

编辑已有用例时，数组值统一显示为“逗号＋一个空格”的形式。

## 后端设计

新增流程使用独立于失效修复的请求语义，避免一个模式参数错误导致误删。后端增加“新增预览”和“确认新增”能力，并复用现有的文档上下文选取、模型调用、AI 响应解析、关键词落地校验和指纹校验逻辑。

新增预览请求包含：

- 所选文档 ID 列表，最多 20 篇；
- 每篇生成数量，范围 1～5。

服务端只接受属于该知识库且状态为“已完成”的文档。对每篇文档生成请求数量的 `REAL_QUERY` 用例，每条用例固定：

- 来源文件为所选文档；
- `minHits = 1`；
- `topK = 5`；
- 期望关键词必须逐字存在于提供给模型的文档上下文中。

新增预览返回知识库文档指纹、现有用例指纹、按文档分组的候选用例及逐文档错误。预览不修改数据库。

确认新增在一个事务中完成：

1. 重新校验文档及用例指纹，防止预览后知识库或用例发生变化；
2. 校验所有文档仍属于当前知识库且状态为“已完成”；
3. 重新校验候选问题、来源文件、关键词、数量和边界；
4. 对现有用例和本批候选用例执行重复检查；
5. 只插入通过校验的新用例，不执行删除或更新；
6. 任一校验失败则整批回滚并要求重新生成预览。

重复判断包括：

- 用例标识在知识库内重复；
- 同一来源文件下，问题经去首尾空格、合并连续空白和忽略大小写后重复。

AI 返回重复候选时，该文档预览标记失败，确认按钮禁用，用户可以重新生成。后端不能为了凑数静默保存重复用例。

## API 边界

保留现有失效修复接口和行为，并新增：

- `POST /api/v1/knowledge-bases/{kbId}/rag-eval/cases/add-generation-preview`
- `POST /api/v1/knowledge-bases/{kbId}/rag-eval/cases/add-generation-confirm`

新增确认请求不得包含待删除用例 ID。服务端从接口层即区分“追加”和“替换”，减少误操作风险。

文档选择列表复用知识库现有文档查询能力，只展示“已完成”的文档；不创建第二份文档清单接口。

## 错误处理

- 没有已完成文档时，“AI 新增用例”不可用并说明原因；
- 未选择文档时，“生成预览”不可用；
- AI 配置缺失、超时、格式错误或关键词未落地时，显示对应文档的错误，不写入数据；
- 预览后文档或用例发生变化时，确认返回冲突并要求重新预览；
- 生成部分成功时仍展示成功候选和失败原因，但整批确认保持禁用，避免用户误以为全部完成；
- 确认失败保留当前用例列表，不产生部分新增。

## 测试

后端覆盖：

- 单篇、多篇及每篇 1～5 条的生成；
- 非本知识库文档、未完成文档、超出数量限制和空选择；
- 预览只读；
- 确认只追加且绝不删除、更新现有用例；
- 用例标识重复、同文档问题重复、本批次内部重复；
- 文档或用例指纹过期；
- 部分 AI 失败与事务回滚。

前端覆盖：

- 常驻入口、文档多选和数量范围；
- 未选择时禁用、生成加载、预览、取消和确认新增；
- 新增流程与失效修复流程文案及行为区分；
- 确认成功后刷新列表；
- 逗号后连续空格不会累积，关键词内部空格保持不变，保存请求仍得到清理后的数组。

## 范围限制

- 首版只生成单文档 `REAL_QUERY` 用例；
- 不自动定时生成，也不在上传文档后自动触发；
- 不提供逐条编辑 AI 预览，用户可以取消后手工新增或重新生成；
- 不改变 RAG 运行、排序、门禁、历史运行或现有失效修复的判定规则；
- 不在新增流程中删除、覆盖或合并现有用例。
